# ArcSite Product Parity Inventory — updated 28 October 2026

## Purpose and method

Use ArcSite as a product-workflow reference for ConstructFlow's tablet-first editor. Reproduce the interaction qualities and complete workflows that fit construction BIM; keep ConstructFlow's visual identity, Thai building workflows, canonical project model, stable UUIDs, renovation phases, and CommandBus.

## Implementation update — 28 October 2026

This update supersedes older statements in the matrix and article map that say canvas bundle placement or Area bundles are not implemented.

- **1. Canvas instances:** Shape, Length/Line, and Area bundles can be placed as canonical `supplier.bundle_instance` SmartObjects with stable UUIDs, active level/phase, canvas rendering, selection, and move support. A placement captures a frozen bundle, component, price, and SKU-choice snapshot.
- **2. Instance configuration and takeoff:** Product Group SKU choices are made for each placement without editing the reusable catalog. Shape quantities are one item, line quantities come from path length, and area quantities come from a validated polygon. Takeoff reads each instance's saved prices so later catalog changes cannot rewrite existing quantities or pricing.
- **3. Area and perimeter formulas:** Area components consume square metres; perimeter components consume the drawn boundary length. Cost, sale rate, and labor are recalculated from the placed geometry and normalized to the measured area. Geometry-dependent bundles cannot be applied as a project-wide static rate. ArcSite Area bundle import is supported where component names, units, and quantities map unambiguously.
- **4. Proposal and report output:** Bundle takeoff lines retain the bundle name, component names, selected Product Group/SKU, multiplier, waste, and area/perimeter basis in their formula. Proposal drafts freeze that formula and show the bundle name as the line description; hidden proposal detail still follows the existing visibility policy.
- **5. Device and integrations:** Tablet placement has snap-aware point, two-tap line, and multi-tap area flows, a live line length preview, area boundary preview, stage instructions, a touch-sized close-polygon action, and Escape cancellation. Created instances use CommandBus, so the existing project save, revision sync, collaboration, undo/redo, PDF/report, and supported webhook/export paths carry the same UUID and snapshot. Provider-specific CRM/accounting connections remain governed by their existing adapter status; physical tablet/stylus review remains open.

## Acceptance spine

- Touch/pen/mouse/keyboard can draw and edit the same canonical objects; a continuous wall gesture is one undoable command batch and a cancel never commits partial geometry.
- Circular wall arcs retain analytic center/radius/angle data through endpoint and exact-length edits, host-distance calculations, openings, snapping, plan/3D representations and adapter export; an edit that no longer fits a hosted opening is rejected without changing the source geometry.
- A takeoff row can select its source object(s); edits to types/geometry recalculate model views and takeoff while preserving UUIDs and phases.
- The takeoff panel can group the currently filtered rows by phase, BOQ cost center, material, or show one flat list; each group subtotal uses only its visible rows, keeps mixed units separate, and sums the same BOQ direct-cost values shown on the rows.
- Selecting objects on the plan exposes direct tablet actions for duplicate/delete and previewed array/offset/mirror; confirming creates one CommandBus undo step, and canceling leaves the source project unchanged.
- Commercial rates and local supplier bundles remain separate from BIM type identity; package costs convert to output-unit rates before entering project rate drafts, and saved proposal snapshots remain unchanged when those catalogs are edited later.
- A Company Library schema-7 bundle contains price books, proposal templates, discount rules, field-form templates, supplier products, Product Groups, bundles, company pricing settings and their shared category order; imports validate all records before one atomic merge, preserve UUIDs and creation dates, reject natural-key/SKU collisions, and keep every bundle component linked to a product in the merged catalog. Schema-1–6 bundles remain importable. Team sync merges records by UUID and update timestamp, applies owner/editor/viewer permissions, and retries optimistic version conflicts; a gateway-assigned company scope shares catalogs across projects, while unassigned accounts remain project-scoped.
- An ArcSite `.xlsx` workbook preview recognizes Products, Product Groups, and Bundles sheets. It imports Products and same-unit Product Groups with a preserved default option, then imports required Shape bundles and Length/Line bundles with simple numeric quantities referencing products or a group’s default member. Length/Line quantities normalize to a per-meter rate and require a matching `m` Rate Key. Group choices remain editable in the reusable Bundle and contribute their selected SKU’s current cost/sale rate to the BOQ preview. Import validates visual-type/unit compatibility and Unit Cost, preserves Input Price as a fixed sell rate, converts supported imperial/metric units to `m`/`m2`/`m3`, preserves hidden flags and existing ConstructFlow UUIDs by supplier/SKU, and requires explicit Rate Key selection when units are ambiguous. Direct group application updates the project-wide selected Rate Key; per-canvas bundle-instance data is future work. Imported bundles remain pricing formulas in the library and are not canvas placements. Optional components, Area bundles (including perimeter-based inputs), per-item tax, and Price Part options are disclosed before commit and never silently included.
- Renaming or merging a Supplier Library category updates matching products, bundles and the shared category order in one IndexedDB transaction; moving categories persists a tablet-friendly order across product and bundle tabs and Company Library transfer/sync. Product/bundle UUIDs and commercial values remain intact, and the atomic rename leaves all three stores unchanged if validation or the write fails; the `ทั่วไป` label maps to records without an explicit category.
- A named discount rule applies its percentage to a proposal draft and freezes rule UUID, name and percentage in the proposal snapshot; changing the catalog later cannot rewrite an existing proposal, and manually editing the percentage removes the rule attribution. The frozen rule provenance appears in A4 output and business-event integrations.
- Field photo dimensions, areas, level, plan pin and camera direction are canonical project data saved through CommandBus; image bytes remain separate local media assets, travel in the versioned `.cfproj` media sidecar, and do not inflate semantic commands or SketchUp sync.
- Field forms can be created from site visit, quality, safety, and client request templates or customized; CSV/XLSX questions can be previewed and validated before saving a reusable company template, including grouped section headings and dropdown choices. - A sent proposal stays stable when catalog prices change; change orders create a new traceable scope and signed price delta snapshot.
